================================================================================
TROUBLESHOOTING
================================================================================

If Backend Not Responding:
  Check: Terminal showing "INFO: Uvicorn running on http://0.0.0.0:8000"
  Restart: Stop and restart backend process

If Frontend Blank:
  Check: Browser console for errors (F12)
  Try: Hard refresh (Ctrl+F5)
  Check: Port 8001 is accessible

If API Returns 500:
  Check: Backend logs in terminal
  Try: Smaller/different image
  Verify: All dependencies installed

If GLB Doesn't Load:
  Check: Network tab shows successful download
  Check: File exists in /output directory
  Try: Manual URL with different path

================================================================================
QUICK REFERENCE
================================================================================

API Endpoint: http://localhost:8000/api/deform
Method: POST
Content-Type: multipart/form-data

Parameters:
  front (required): Image file
  side (optional): Image file
  top (optional): Image file
  color (optional): Hex color string
  template (optional): Template name

Response:
  download_url: Path to GLB file
  measurements: Detected dimensions
  template: Used template name
  pipeline: Processing stages with timing
